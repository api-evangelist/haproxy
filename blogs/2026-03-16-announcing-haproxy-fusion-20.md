                <p>Today, we announce the release of HAProxy Fusion 2.0. This release marks a generational leap for the authoritative control plane that orchestrates HAProxy Enterprise’s high-performance application delivery and security. With a combination of new headliner features, structural changes, and improvements to the  performance of the underlying API, HAProxy Fusion has jumped from version 1.3 to version 2.0.</p><p>HAProxy Fusion 2.0 enables modern security management, cloud-native deployment and service discovery, and numerous enhancements to automation, access management, and scalability that will propel HAProxy One — and the innovative applications that depend on it — into a new era.</p>
                
            
                
            
                <h2 id="new-to-haproxy-fusion">New to HAProxy Fusion?</h2><p><a href="http://production.int.haproxy.com/products/haproxy-fusion-control-plane">HAProxy Fusion</a> provides full-lifecycle management, monitoring, and automation of multi-cluster, multi-cloud, and multi-team HAProxy Enterprise deployments. HAProxy Fusion combines a high-performance control plane with a modern GUI and API, enterprise administration, a comprehensive observability suite, and infrastructure integrations including AWS, Kubernetes, Consul, and Prometheus. </p><p>Together, this flexible data plane, scalable control plane, and secure edge network form HAProxy One: the world’s fastest application delivery and security platform that is the G2 category leader in load balancing, API management, container networking, DDoS protection, and web application firewall (WAF). </p>
                
            
                <img alt="" height="900" src="https://cdn.haproxy.com/img/containers/posts/g2-badges---fusion-2.0-blog.png/e2c4570da954dba59b8269ce69adac6b/g2-badges---fusion-2.0-blog.png" width="1800" />
                
            
                <p>To learn more, <a href="http://production.int.haproxy.com/contact-us">contact our team</a> for a demonstration.</p><h2 id="whats-new-in-haproxy-fusion-20">What’s new in HAProxy Fusion 2.0</h2><p>This release introduces significant enhancements to security, automation, and scale, and support for <a href="http://production.int.haproxy.com/products/haproxy-enterprise">HAProxy Enterprise load balancer</a> versions <a href="http://production.int.haproxy.com/blog/announcing-haproxy-enterprise-3-1">3.1</a> and <a href="http://production.int.haproxy.com/blog/announcing-haproxy-enterprise-3-2">3.2</a>.</p>
                
            
                
            
                <h2 id="upgrade-to-haproxy-fusion-20">Upgrade to HAProxy Fusion 2.0</h2><p>When you&#039;re ready to start the upgrade process, please carefully read our <a href="https://customer-docs.haproxy.com/haproxy-fusion/getting-started/upgrade/">HAProxy Fusion upgrade documentation</a> (customer login required).</p><h2 id="modern-security-management">Modern security management</h2><p>HAProxy Fusion 2.0 introduces a unified “security control plane” to orchestrate the multi-layered security capabilities in HAProxy Enterprise. This architecture combines the next-gen performance of HAProxy Enterprise’s security layers — powered by threat intelligence enhanced by machine learning — with a next-gen security UX. </p><p>This powerful combination makes it simple to implement common security patterns (such as <a href="http://production.int.haproxy.com/solutions/security">Web App and API Protection</a>), or add edge security to complex traffic management solutions (such as <a href="http://production.int.haproxy.com/solutions/universal-mesh">Universal Mesh</a> and <a href="http://production.int.haproxy.com/solutions/automation-and-self-service">Load Balancing as a Service (LBaaS)</a>, while providing easy access to flexible building blocks and deep customization for those who need it.</p><h3 id="centralized-security-policy">Centralized security policy</h3><p>HAProxy Fusion includes centralized security policy to orchestrate the multi-layered security capabilities of HAProxy Enterprise, in any environment or form factor, including: </p><ul><li><p><a href="http://production.int.haproxy.com/solutions/bot-management">HAProxy Enterprise Bot Management Module</a>, powered by the new <a href="https://www.haproxy.com/blog/announcing-haproxy-enterprise-3-2#next-generation-security-and-intelligence">Threat Detection Engine</a>, which uses reputational and behavioral signals to accurately identify humans, verified bots (such as search engine and AI crawlers), and malicious bots; and detect and label complex and high-impact threats, including application layer DDoS attacks, brute force attacks, web scrapers, and vulnerability scanners.</p></li><li><p><a href="http://production.int.haproxy.com/solutions/web-application-firewall">HAProxy Enterprise WAF</a>, powered by the Intelligent WAF Engine, which detects and mitigates application attacks, such as SQL injection, XSS, CSRF, and more.</p></li><li><p>HAProxy Enterprise’s security building blocks, such as the Global Profiling Engine (GPE), ACLs, CAPTCHA Module, allow-lists and deny-lists, and more.</p></li></ul><h3 id="security-profiles">Security Profiles</h3><p>HAProxy Fusion makes centralized security policy fast and easy to deploy with “Security Profiles”. Security Profiles provide preset security policies that administrators can apply in just a few clicks to simplify configuration and secure traffic into new applications. </p><p>HAProxy Fusion provides a default Security Profile to help administrators to get started quickly. The default Security Profile includes intelligent presets suitable for common application types. Administrators can easily create customized Security Profiles, tailored to particular use cases, that can be reused or further customized as new use cases emerge.</p>

                <h3 id="threat-response-matrix">Threat-Response Matrix</h3><p>HAProxy Fusion’s Security Profiles make it simple to create and customize full-spectrum security policies with an intuitive visual policy builder called the “Threat-Response Matrix”. Part of HAProxy Fusion’s <a href="http://production.int.haproxy.com/solutions/haproxy-gui-graphical-user-interface">modern web GUI</a>, the Threat-Response Matrix enables administrators to orchestrate the multi-layered security capabilities in HAProxy Enterprise without requiring detailed knowledge of HAProxy’s configuration language or the underlying modules.</p><p>Using the Threat-Response Matrix, administrators can: </p><ul><li><p>Combine Monitored Signals and Decisions, using a response framework based on simple thresholds and standard logical operators</p></li><li><p>View and apply a recommended Decision for each Monitored Signal (recommendations provided by HAProxy Fusion)</p></li><li><p>See a clear visual representation of how the Monitored Signals and Decisions are connected </p></li><li><p>See how a new Security Profile will affect real-time traffic in Learning Mode</p></li><li><p>Seamlessly toggle between Learning Mode and Enforcement Mode when a Security Profile is ready for production traffic</p></li></ul>

                <h2 id="enhanced-service-discovery">Enhanced service discovery</h2><p>HAProxy Fusion 2.0 introduces deep support for Consul Enterprise, including partitions, namespaces, and the key-value store. Consul support now also includes the key-value store. This enhanced <a href="http://production.int.haproxy.com/solutions/service-discovery">service discovery</a> natively understands complex Consul and Consul Enterprise architectures.</p><p>This release adds variable and map transformers, allowing users to extract specific Consul and Kubernetes metadata and map them directly to HAProxy configuration directives. This includes Consul tags and meta key-value pairs, and Kubernetes annotations, version tags, and canary labels.</p><p>Conditional automation also allows for logic-based configuration generation. These enhancements enable true multi-tenancy, allowing HAProxy Enterprise deployments to securely manage traffic for disparate teams across complex architectures.</p>
                
            
                <figure><img alt="" height="1100" src="https://cdn.haproxy.com/assets/posts/haproxy-fusion-service-discovery.svg" width="1800" /><figcaption><p><em>Kubernetes and Consul service discovery in HAProxy Fusion 2.0</em></p>
</figcaption></figure>
                
            
                <h2 id="native-kubernetes-deployment">Native Kubernetes deployment</h2><p>HAProxy Fusion 2.0 introduces the HAProxy Fusion Operator, which allows the control plane to be deployed natively inside Kubernetes clusters, as part of our broader <a href="http://production.int.haproxy.com/solutions/kubernetes">Kubernetes solution</a>. The HAProxy Fusion Operator deploys directly into your cluster via a manifest applied using <code>kubectl</code>.</p><p>The operator automates image configuration and orchestrates essential services. This fully provisions the control plane and its databases in under five minutes.</p><h2 id="full-lifecycle-automation">Full-lifecycle automation</h2><p>HAProxy Fusion 2.0 introduces an official Terraform Provider and enhanced Ansible Playbook support specifically for managing HAProxy Fusion resources.</p><p>Administrators can now declare the desired state of their HAProxy Enterprise clusters, groups, and configurations. This enables granular configuration as code, effectively managing individual configuration objects like frontends and backends.</p><h2 id="zero-touch-user-provisioning">Zero-touch user provisioning</h2><p>HAProxy Fusion 2.0 enables automatic role mapping. Administrators can configure HAProxy Fusion to read group claims from the OpenID Connect (OIDC) token and automatically assign the corresponding internal RBAC role.</p><p>This dynamically translates Identity Provider groups to HAProxy Fusion roles, automating onboarding and offboarding. This integration ensures users immediately have the correct permissions upon login.</p>

                <h2 id="high-performance-api-and-enhanced-gui">High-performance API and enhanced GUI</h2><p>The new <a href="https://customer-docs.haproxy.com/haproxy-fusion-api/">HAProxy Fusion API</a> v2 is re-engineered for higher performance at scale. It is designed to handle hyperscale bursts without increasing latency. The API supports order-of-magnitude larger configurations and a significantly higher number of frontends and backends.</p><p>Additionally, the user interface has been reorganized to create a more intuitive workflow. Configuration fields are now logically grouped by section into tabs. Frontend and backend templates include tabs for general properties, performance and stability, traffic management, and security and advanced settings.</p><h2 id="extended-product-lifecycle">Extended product lifecycle</h2><p>Starting with HAProxy Fusion 2.0, every release is now a Long-Term Support (LTS) version. This provides a <strong>standardized lifecycle of two years</strong> of active support followed by six months of migration support, during which customers will be guided by our support team to upgrade their infrastructure to the latest version before the end of the support period.</p><p>This extended commitment offers the stability and predictability enterprise teams need to plan infrastructure updates on their own terms and maximize the return on investment for each deployment.</p><h2 id="try-haproxy-fusion-20">Try HAProxy Fusion 2.0</h2><p>If you haven’t tried the power of HAProxy Fusion, this is the perfect time to schedule a demo with our team. SecOps and DevOps teams — this one’s for you!</p><p>There has never been a better time to start using HAProxy Fusion. <a href="http://production.int.haproxy.com/fusion-demo">Request a demo</a> or visit our documentation to <a href="https://customer-docs.haproxy.com/haproxy-fusion/getting-started/upgrade/">begin your upgrade</a>.</p>
